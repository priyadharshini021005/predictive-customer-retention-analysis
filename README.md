# Predictive Customer Retention Analysis

An end-to-end customer retention and churn analytics project using **MySQL, SQL, Python, Excel, Power BI, and DAX**. The project analyzes customer purchasing behavior, retention patterns, cohort performance, and behavioral risk to identify customers who may require retention-focused interventions.

## 📌 Project Overview

Customer retention is an important business metric for understanding repeat purchasing behavior and identifying potential churn.

This project develops a complete analytics workflow that:

- Validates raw customer and transaction data using Python
- Loads and processes data using MySQL
- Applies lifecycle eligibility rules
- Performs customer retention and RFM analysis
- Calculates customer behavioral risk scores using deterministic SQL logic
- Builds Power BI-ready analytical views
- Creates interactive Power BI dashboards
- Identifies high-risk customers and churn candidates
- Provides retention and customer-behavior insights

> **Note:** The risk score used in this project is a deterministic SQL-based behavioral scoring approach and is **not a machine-learning prediction model**.

## 🎯 Objectives

- Analyze customer purchasing behavior
