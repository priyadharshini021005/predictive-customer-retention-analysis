## Step 1 — Create Database

Create the database and use it.

## Step 2 — Create Tables

Create these four core tables:

### customers

Columns:

* customer_id — INT, PRIMARY KEY
* customer_name — VARCHAR
* gender — VARCHAR
* age — INT
* city — VARCHAR
* state — VARCHAR
* signup_date — DATE
* customer_segment — VARCHAR

### products

Columns:

* product_id — INT, PRIMARY KEY
* product_name — VARCHAR
* category — VARCHAR
* sub_category — VARCHAR
* price — DECIMAL

### orders

Columns:

* order_id — INT, PRIMARY KEY
* customer_id — INT, FOREIGN KEY
* order_date — DATE
* order_status — VARCHAR
* payment_method — VARCHAR
* total_amount — DECIMAL

Foreign key:

`orders.customer_id → customers.customer_id`

### order_items

Columns:

* order_item_id — INT, PRIMARY KEY
* order_id — INT, FOREIGN KEY
* product_id — INT, FOREIGN KEY
* quantity — INT
* unit_price — DECIMAL
* discount — DECIMAL
* item_total — DECIMAL

Foreign keys:

`order_items.order_id → orders.order_id`

`order_items.product_id → products.product_id`

## Step 3 — Constraints

Use appropriate:

* PRIMARY KEY
* FOREIGN KEY
* NOT NULL
* UNIQUE where appropriate
* CHECK constraints where supported and useful

Do not overuse constraints that could prevent valid historical data from being imported.

## Step 4 — Indexes

Create appropriate indexes for:

* Foreign-key integrity
* Invalid customer references

* Invalid dates

Compare the imported row counts with the Phase 2 CSV files.
